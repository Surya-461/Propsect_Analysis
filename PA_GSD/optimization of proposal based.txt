5. Research Layer: Group Related Parameters into Shared Queries
🔴 Current Bottleneck:
If a user selects "Claims Management", "Claims Settlement Ratio", and "Digital Claims Intake", the research router runs 3 separate search passes (6 queries total) for essentially the same topic.

🟢 Optimization:
Use the Source Grouping Engine in 
proposal_master_checklist.py:group_parameters_by_source
:

python


# Group parameters sharing the same data source (e.g. 'claims_ops')
grouped_parameters = {
    "claims_operations": ["Claims Management", "Claims Settlement Ratio", "Digital Claims Intake"],
    "financial_strength": ["Solvency Ratio", "Underwriting Profit", "Credit Rating"]
}
Run 1 high-yield query per group instead of 1 query per parameter.
Result: Reduces Tavily/Serper search calls by 40–50% while providing more cross-referenced evidence to the LLM.
